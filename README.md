> The judge scored my joke zero, then scored itself full marks for judging — turns out the only joke it truly loved was its own rubric.

## What this is

A one-line entry for the make.fun competition "Make the AI Judge Laugh": a single original joke about an AI judge that grades a joke, then grades itself — and falls in love with its own rubric.

## Run it

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## Notes

- Standard library only (`os`).
- The line is exactly one line, at most 280 characters, enforced before writing.
